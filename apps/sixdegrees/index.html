How it works

Local-first by default, GitHub sync when you want it.

1

Capture locally

All data lives in on-device SQLite — fast, private, and available offline.

2

Sync to GitHub

Mirror your graph as JSON files in a private GitHub repo using git.

3

Resolve conflicts

If two devices change the same record, you decide which version to keep.

Backup or restore in one tap

Replace remote data with local, or restore local from GitHub when you need to reset.

Privacy you can verify

Six Degrees keeps your graph in your own GitHub repository. You can inspect every JSON file, version history, and sync commit. Nothing is stored on a third-party server.

  • Offline-first, local SQLite storage
  • Your GitHub repo is the cloud backup
  • Git history tracks every sync
  • Secure OAuth + device code login

FAQ

Answers to the most common questions.

Is my data stored on your servers?

No. Data lives on your device and optionally in your own GitHub repository.

Do I need GitHub?

No. The app works offline without GitHub. Sync is optional.

Can I import my contacts?

Yes. You can import contacts, detect duplicates, and refine your list.

Which platforms are supported?

Six Degrees is built with React Native and targets Android and iOS.
